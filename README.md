# Nihal M — Portfolio

Personal portfolio website built with Next.js, deployed on Vercel.

## Live

https://nihalm.vercel.app/

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Deployment

Deployed on [Vercel](https://vercel.com).
